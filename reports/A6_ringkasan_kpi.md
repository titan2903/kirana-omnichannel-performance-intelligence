# A6. Ringkasan KPI (kamus metrik)

Dua belas KPI hidup sebagai view di schema `metrics`; kartu Metabase hanya `SELECT` dari view itu. Rasio dihitung ulang dari pembilang
dan penyebut setelah filter (tidak pernah AVG kolom persen). Definisi bisnis dan aturan inklusi/eksklusi lengkap ada di Lampiran A7;
tabel ini dihasilkan dari `metrics.kpi_dictionary` yang sama.

| #  |               KPI               |                                                                    Rumus SQL                                                                     |                                           Grain                                           |                             Pemilik                              |                                                                                   Target / ambang                                                                                   |
|---:|---------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------|-------------------------------------------------------------------------------------------|------------------------------------------------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 1  | Net Sales                       | `SUM(net_sales_idr)`                                                                                                                             | bulan x channel x region (dasar target, region_target_basis) x toko x kategori x flag B2B | Finance Controller                                               | Target bulanan FP&A per channel/region (FY2025 Rp 44,181 miliar; H1 2026 Rp 23,820 miliar, semua channel). Tidak ada target 2024.                                                   |
| 2  | Achievement vs Target %         | `100 * SUM(net_sales_idr) / NULLIF(SUM(target_net_sales_idr), 0)`                                                                                | bulan x channel x region (Store) atau nasional (online)                                   | Direktur Komersial                                               | Hijau >= 100%; Kuning 90 sampai <100%; Merah < 90% (ASUMSI analis, ref_status_threshold).                                                                                           |
| 3  | Gross Margin %                  | `100 * SUM(gross_margin_idr) / NULLIF(SUM(net_sales_idr), 0)`                                                                                    | bulan x channel x region x toko x kategori                                                | Finance Controller                                               | Target GM FP&A per channel: Store 46%, Website 45%, Mobile App 43%, Marketplace 42%. Hijau: selisih >= 0 pt; Kuning: sampai -2 pt; Merah: lebih dari 2 pt di bawah target (ASUMSI). |
| 4  | Contribution Margin %           | `100 * SUM(contribution_margin_idr) / NULLIF(SUM(net_sales_idr), 0)`                                                                             | bulan x channel x region x toko x kategori                                                | Finance Controller                                               | Target turunan = Target GM - tarif channel berlaku (ASUMSI; FP&A tidak menetapkan target CM). Status memakai ambang selisih yang sama dengan Gross Margin.                          |
| 5  | Return Rate                     | `100 * SUM(refund_idr) / NULLIF(SUM(net_sales_idr), 0); 100 * SUM(return_qty) / NULLIF(SUM(qty_sold), 0)`                                        | bulan x channel x region x kategori                                                       | Head of Store Operations (Store); Head of E-Commerce (online)    | Tidak ada target resmi; pembanding historis                                                                                                                                         |
| 6  | Average Order Value (AOV)       | `SUM(net_sales_idr) / NULLIF(SUM(transactions), 0)`                                                                                              | bulan x channel x region x toko x member x B2B                                            | Direktur Komersial                                               | Tidak ada target resmi; pembanding historis                                                                                                                                         |
| 7  | Jumlah Transaksi                | `SUM(transactions)`                                                                                                                              | bulan x channel x region x toko x member x B2B                                            | Direktur Komersial                                               | Tidak ada target resmi; pembanding historis                                                                                                                                         |
| 8  | Active Members                  | `active_members (pilih satu period_type, filter period_start dan channel_name)`                                                                  | tipe periode (Bulan, Kuartal, Semester, Tahun) x periode x channel (+ Semua channel)      | Head of E-Commerce (online); Head of Store Operations (Store)    | Tidak ada target resmi; pembanding historis                                                                                                                                         |
| 9  | Repeat Rate                     | `100 * repeat_members / NULLIF(active_members, 0)`                                                                                               | tipe periode x periode x channel (+ Semua channel)                                        | Head of E-Commerce (online); Head of Store Operations (Store)    | Tidak ada target resmi; pembanding historis                                                                                                                                         |
| 10 | Promo Lift dan Dampak Margin    | `lift_net_pct = 100 * (net_sales_idr / baseline_net_sales_idr - 1); incremental_gross_margin_idr = gross_margin_idr - baseline_gross_margin_idr` | satu kode promo (73)                                                                      | Direktur Komersial (Marketing)                                   | Tidak ada target resmi; pembanding historis                                                                                                                                         |
| 11 | Cancellation Rate dan Void Rate | `100 * SUM(cancelled_net_sales_idr) / NULLIF(SUM(valid_net_sales_idr) + SUM(cancelled_net_sales_idr), 0)`                                        | bulan x channel x region                                                                  | Head of E-Commerce (pembatalan); Head of Store Operations (void) | Tidak ada target resmi; pembanding historis                                                                                                                                         |
| 12 | Promo Budget Utilization        | `100 * SUM(discount_idr) / NULLIF(SUM(budget_idr), 0)`                                                                                           | satu kode promo                                                                           | Finance Controller; Direktur Komersial (Marketing)               | Batas atas 100% dari anggaran promo.                                                                                                                                                |
